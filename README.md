## 🎯 Problem Statement
Buying or selling a house requires a fair price estimate. This project builds a regression model that
estimates a house's price using features such as area, bedrooms, location and condition, and exposes the
model through a simple web interface so anyone can get an instant prediction.

## 📊 Dataset
File: `data/house_prices.csv` — **3,000 records**, 10 input features + 1 target.

| Feature | Type | Description |
|---------|------|-------------|
| `area_sqft` | Numeric | Built-up area in square feet |
| `bedrooms` | Numeric | Number of bedrooms |
| `bathrooms` | Numeric | Number of bathrooms |
| `floors` | Numeric | Number of floors |
| `age_years` | Numeric | Age of the house |
| `garage_spaces` | Numeric | Number of garage spaces |
| `has_pool` | Binary | 1 = has swimming pool |
| `distance_to_city_km` | Numeric | Distance from city centre |
| `location` | Categorical | Downtown / Suburban / Rural / Waterfront |
| `condition` | Categorical | Poor / Fair / Good / Excellent |
| **`price`** | **Target** | House price in USD |

> ℹ️ The dataset is **synthetic**, generated by `generate_data.py`, so the project works out of the box.
> It can be replaced with a real dataset (e.g. Kaggle *House Prices*) by updating the column lists in the notebook.

## 🔄 Project Workflow
1. **Data loading** – read CSV into Pandas
2. **Data cleaning** – handle missing values (median imputation) and duplicates
3. **EDA** – price distribution, correlation heatmap, price vs. area/location/condition
4. **Preprocessing pipeline** – `SimpleImputer` + `StandardScaler` for numeric, `OneHotEncoder` for categorical (via `ColumnTransformer`)
5. **Model training** – Linear Regression, Ridge, Random Forest, Gradient Boosting with 5-fold cross-validation
6. **Hyperparameter tuning** – `RandomizedSearchCV` on Gradient Boosting
7. **Evaluation** – R², MAE, RMSE, actual-vs-predicted and residual plots, feature importance
8. **Deployment** – save pipeline with Joblib and serve it using Streamlit

## 🏆 Results
Best model: **Gradient Boosting Regressor** (evaluated on a held-out 20% test set)

| Metric | Score |
|--------|-------|
| R² Score | **≈ 0.97** |
| MAE | ≈ $18,700 |

## ⚙️ Installation & Setup (Step by Step)

### Step 1 — Prerequisites
Install **Python 3.9+** and **Git**. Check:
```bash
python --version
git --version
```

### Step 2 — Clone the repository
```bash
git clone https://github.com/<your-username>/house-price-prediction.git
cd house-price-prediction
```

### Step 3 — Create a virtual environment (recommended)
```bash
# Windows
python -m venv venv
venv\Scripts\activate

# macOS / Linux
python3 -m venv venv
source venv/bin/activate
```

### Step 4 — Install dependencies
```bash
pip install -r requirements.txt
```

### Step 5 — (Optional) Regenerate the dataset
```bash
python generate_data.py
```

### Step 6 — Run the Jupyter Notebook
```bash
jupyter notebook
```
Open `notebooks/house_price_prediction.ipynb` and click **Kernel → Restart & Run All**.
This trains the models and saves `models/house_price_model.pkl`.

### Step 7 — Launch the web app
From the project root folder:
```bash
streamlit run app.py
```
The app opens at **http://localhost:8501**.

## 💻 How to Use the Web App
1. Enter property details (area, bedrooms, bathrooms, floors, garage, age, distance).
2. Choose **location** and **condition**, and tick the pool option if applicable.
3. Click **Predict price** to see the estimated price instantly.

## ☁️ Deploy Online (Free)
1. Push this project to a public GitHub repository.
2. Go to [share.streamlit.io](https://share.streamlit.io) and sign in with GitHub.
3. Click **New app** → select your repository and branch `main`.
4. Set **Main file path** to `app.py` and click **Deploy**.
5. Add the live link here: `https://<your-app-name>.streamlit.app`
